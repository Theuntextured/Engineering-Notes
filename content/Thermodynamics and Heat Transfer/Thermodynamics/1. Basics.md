# Systems
## Definitions

> [!WARNING] Systems
> A system is whatever we want to study:
> - A quantity of matter or region in space
> - Can be simple or complex
> - Composition and quantity of matter within may change or not


| Term                                     | Definition                                                                                                                                                                                                                                     |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Surroundings                             | Mass or region outside the system.                                                                                                                                                                                                             |
| Universe                                 | Union of system and surroundings.                                                                                                                                                                                                              |
| Boundary                                 | Surface (real or ideal) separating the system from its surroundings. Interface between the two. Can be rigid or movable.                                                                                                                       |
| Property                                 | Macroscopic feature of a system (e.g. $m,V,T\dots$)                                                                                                                                                                                            |
| Extensive Properties                     | Properties with numerical value proportional to the quantity of matter contained within the system. They are additive. (e.g. $m,V,E\dots$)                                                                                                     |
| Intensive Properties                     | Properties whose numerical value is independent of quantity of matter. They are NOT additive. (e.g. $p,T\dots$)                                                                                                                                |
| Specific Properties                      | Ratio between two extensive properties (e.g. $v = \frac{V}{m}$ in $m^{3}kg$)                                                                                                                                                                   |
| State                                    | The condition of the system as described by its properties. Not all properties are needed, since many depend on others.                                                                                                                        |
| Steady state                             | A system is at steady state if all properties are constant over time. For thermodynamic equilibrium it must be at mechanical ($\sum F=0,\sum p=0$), thermal ($\frac{dT}{dt}=0$), chemical (No chemical reactions occur) and phase equilibrium. |
| Process                                  | A transformation in a system.                                                                                                                                                                                                                  |
| Path                                     | The series of equilibrium states through which a system passes during a process.                                                                                                                                                               |
| Thermodynamic Process                    | The series of processes that begins and ends at the same state.  No net change of state occurs. Properties are independent of the details of the process.                                                                                      |
| Quasi-equilibrium (quasi-static) process | A process that proceeds in such matter that the system is infinitesimally close to an equilibrium state at all time. It is an idealized process. The whole system can be described by only one numerical value for each property.              |
| Actual Process                           | Equilibrium is only satisfied at the beginning and end of the process. There is spacial variation in properties and therefore one numerical value per property is insufficient.                                                                |
