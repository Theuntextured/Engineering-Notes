# Cheat Sheet — Evaluation of Measurement Uncertainty

> GUM method with the lab's uncertainty budget table ("UncTab"). Goal: from a mathematical model $y = f(x_1, x_2, \dots)$ and the metrological characteristics of each input, compute the **expanded uncertainty** $U(y) = k \cdot u(y)$. Symbols: $u(x_i)$ = standard uncertainty, $c_i$ = sensitivity coefficient, $\nu$ = degrees of freedom, $k$ = coverage factor, $P$ = confidence level.

---

## Golden Rules (they cost points if ignored)

- **NEVER use multiples or submultiples of the measurement units.** Convert everything to base SI first (mm → m, µm/m → m/m, kg/dm³ → kg/m³, mW/°C → W/°C…).
- Write the **mathematical model** first; every uncertainty factor must enter through it (add correction terms like bias, resolution as $+0$ variables if needed).
- Classify every factor as **Statistical (Type A)** or **Non-statistical (Type B)** before touching formulas.

## 1. The GUM Procedure — 8 Steps

| # | Step | Output |
| :--- | :--- | :--- |
| 1 | Write the model $y = f(x_1, \dots, x_n)$ | Value of $y$ from input values |
| 2 | List all uncertainty factors per variable (bias, resolution, repeatability, reproducibility, tolerance, temperature…) | One row per factor in the table |
| 3 | Convert each factor to a **variance** $u^2(x_i)$ | Type A/B recipes below |
| 4 | Sensitivity coefficients $c_i = \partial y / \partial x_i$ | Analytical or numerical |
| 5 | Combine: $u^2(y) = \sum_i c_i^2 \, u^2(x_i)$ | Combined variance |
| 6 | Effective d.o.f. (Welch–Satterthwaite) | $\nu_{eff}$ |
| 7 | Coverage factor $k = t_{1-\alpha/2}(\nu_{eff})$ | `T.INV(1−(1−P)/2; ν_eff)` |
| 8 | Expanded uncertainty | $U(y) = k \cdot u(y)$; result $= y \pm U(y)$ at confidence $P$ |

## 2. Converting Each Factor to a Standard Uncertainty

### Type A — Statistical (from measured data)

| Information given | $u(x)$ | d.o.f. $\nu$ |
| :--- | :--- | :--- |
| Repeatability/reproducibility as st.dev. $s$ from $q$ preliminary tests | $u = s$ | $q - 1$ |
| Variance $s^2$ from $q$ replications | $u = \sqrt{s^2}$ | $q - 1$ |
| Result is the **average of $m$ measurements** | divide the *variance* by $m$: $u^2 \to s^2/m$ | unchanged |

### Type B — Non-statistical (from certificates, specs, handbooks)

| Information given | Distribution assumed | $u^2(x)$ | d.o.f. |
| :--- | :--- | :--- | :--- |
| Expanded uncertainty $U$ at confidence $P$ with $\nu$ d.o.f. (calibration certificate) | Student | $u = U / t_{P,\nu}$, then $u^2$ | $\nu$ (declared) |
| Expanded uncertainty $U$ with coverage factor $k$ | Normal | $u = U/k$ | $\infty$ |
| Tolerance / maximum error $\pm a$ (half-range) | Uniform | $a^2/3$ | $\infty$ |
| Resolution $r$ (full step) | Uniform on $\pm r/2$ | $(r/2)^2/3 = r^2/12$ | $\infty$ |
| Repeatability as **maximum difference between results** (range $R$) | Uniform on $\pm R/2$ | $(R/2)^2/3$ | $\infty$ |
| Variability interval $\pm a$ (e.g. temperature $22 \pm 5\,°C$, air density range) | Uniform | $a^2/3$ | $\infty$ |
| Cyclic error, half-range $a$ (e.g. thread pitch) | Uniform | $a^2/3$ | $\infty$ |
| Relative uncertainty $\%$ on value $x$ | — | convert to absolute first: $a = \% \cdot x$ | as declared |

> [!TIP] The two reflexes
> Given a **half-interval** → divide² by 3. Given an **expanded uncertainty** → divide by $k$ (or $t$). Given a **standard deviation** → use as is. Averaging $m$ readings → random contributions get $/m$ (bias does NOT: it doesn't average out).

## 3. Sensitivity Coefficients $c_i = \partial y / \partial x_i$

| Method | How |
| :--- | :--- |
| **Analytical** | Differentiate the model (fine for simple models) |
| **Numerical (the lab's way)** | Perturb one input at a time: $c_i = \dfrac{f(x_i + \delta_i) - y}{\delta_i}$ with a small $\delta_i$ (e.g. $u(x_i)/100$); all other variables at nominal |

Rows sharing the same physical variable (e.g. bias, resolution, repeatability of the same instrument) share the same $c_i$.

## 4. Combination, Effective d.o.f., Expanded Uncertainty

| Quantity | Formula | Excel |
| :--- | :--- | :--- |
| Contribution of factor $i$ | $P_i = c_i^2 \, u^2(x_i)$ | one column of the table |
| Combined variance | $u^2(y) = \sum_i P_i$ | `SUM` |
| Combined standard uncertainty | $u(y) = \sqrt{u^2(y)}$ | `SQRT` |
| Welch–Satterthwaite | $\nu_{eff} = \dfrac{\left[u^2(y)\right]^2}{\sum_i P_i^2 / \nu_i}$ — round **down** | `INT(u⁴ / SUM(Pᵢ²/νᵢ))` |
| Coverage factor | $k = t_{1-\alpha/2}(\nu_{eff})$ | `T.INV(1−(1−P)/2; ν_eff)` |
| Expanded uncertainty | $U(y) = k \cdot u(y)$ | — |

Factors with $\nu = \infty$ (Type B uniform) contribute $0$ to the Welch–Satterthwaite denominator → they *increase* $\nu_{eff}$.

## 5. The Uncertainty Budget Table (UncTab layout)

One row per uncertainty factor:

| Column | Content |
| :--- | :--- |
| Variable / Symbol / Value | Input $x_i$ in SI units |
| Factor | Bias · Resolution · Repeatability · Reproducibility · Tolerance · Temperature… |
| Statistical? | Type A (with $\nu = q-1$) or Type B ($\nu = \infty$) |
| Information | What is declared (range, st.dev., expanded unc., …) |
| $u^2(x_i)$ | Via the conversion table (§2), including $/m$ if averaged |
| $\nu_i$ | d.o.f. of the factor |
| $c_i = \partial y / \partial x_i$ | Sensitivity (§3) |
| $P_i = c_i^2 u^2(x_i)$ | Contribution to $u^2(y)$ |
| $P_i^2 / \nu_i$ | For Welch–Satterthwaite |

Bottom of the table: $u^2(y) \to u(y) \to \nu_{eff} \to k \to U(y)$.

## 6. Recurring Follow-up Questions

| Question | Recipe |
| :--- | :--- |
| **Most impacting factor** (to reduce uncertainty) | Rank rows by $P_i$; the max dominates ($u$ adds in quadrature, so only the biggest matters) |
| **Least impacting factor** (to reduce costs) | The min $P_i$: relax its requirement / use a cheaper instrument |
| **"What if" analysis** | Halve the dominant factor's uncertainty, recompute $U(y)$, quote the new value |
| **Number of replications $m$ for an uncertainty goal** | The averaged (random) contributions scale as $1/m$: increase $m$ until $U(y) \le U_{goal}$ (trial in the sheet; bias terms do not decrease) |
| **Bias correction with temperature** | Include the model correction, e.g. $L_{20} = L_T \left[1 + (\alpha_{piece} - \alpha_{instr})(20 - T)\right]$ |

## 7. The Lab's Mathematical Models (for reference)

| Exercise | Model |
| :--- | :--- |
| **Length at 20 °C** (UncTab) | $L_{20} = L_T \left[1 + (\alpha_p - \alpha_i)(20 - T)\right]$; $T = 22 \pm 5\,°C$ uniform |
| **Strain rosette** (Ex 1-01) | $\varepsilon_1 = f(\varepsilon_a, \varepsilon_b, \varepsilon_c)$: $\frac{\varepsilon_a+\varepsilon_c}{2} + \sqrt{\left(\frac{\varepsilon_a+\varepsilon_c}{2}-\varepsilon_b\right)^2 + \left(\varepsilon_a - \frac{\varepsilon_a+\varepsilon_c}{2}\right)^2}$ — three gauges, each with resolution + repeatability + reproducibility + bias |
| **Thread mean diameter, 3-wire method** (Ex 1-02) | $d_2 = M - d_w\left(1 + \dfrac{1}{\sin(\theta/2)}\right) + \dfrac{p}{2\tan(\theta/2)}$ — tolerances on $d_w$ and $p$ uniform; micrometer spread + resolution |
| **Pressure balance** (Ex 2-01) | $p = \dfrac{m\,g\,(1 - \rho_{air}/\rho_{mass})}{\pi\left(\frac{D+d}{4}\right)^2}$ — effective area from mean piston/cylinder diameter |
| **Thermometer waiting time** (Ex 2-02) | $t = -\dfrac{C}{K}\ln\dfrac{\Delta T_{req}}{\Delta T_0}$ — $C$, $K$ with 10% expanded uncertainty; take the **upper limit of the CI** as required waiting time |

## 8. Excel Quick Reference

| Task | Function |
| :--- | :--- |
| Coverage factor / $t$ from confidence $P$ and $\nu$ | `T.INV(1−(1−P)/2; ν)` (bilateral) |
| Convert declared $U$ (conf. $P$, $\nu$ d.o.f.) to $u$ | `U / T.INV(1−(1−P)/2; ν)` |
| Effective d.o.f. | `INT( SUM(Pᵢ)^2 / SUM(Pᵢ²/νᵢ) )` |
| Numerical sensitivity | perturbed $f$ minus nominal $f$, divided by the perturbation |

## 9. Worked Micro-Example of the Flow

1. Model: $y = f(x)$; value $y_0$.
2. Rows: bias ($U{=}3.7$ µm on avg of 4, $\nu{=}3$, conf. 95%) → $u = 3.7/t_{95\%,3}$; resolution 1 µm → $u^2 = (0.5)^2/3$; repeatability $s = 1.3$ µm (declared) averaged over $m{=}5$ → $u^2 = 1.3^2/5$; reproducibility $s^2 = 10.7$ µm², $q{=}10$ tests, over $m$: $u^2 = 10.7/5$, $\nu = 9$; temperature $\pm 5\,°C$ uniform → $u^2 = 25/3$ with $c = L(\alpha_p - \alpha_i)$.
3. $u^2(y) = \sum c_i^2 u_i^2 \to u(y) \to \nu_{eff} \to k \to U(y) = k\,u(y)$.
4. Report: $y = y_0 \pm U(y)$ at $P$; dominant factor = largest $P_i$.
