# Cheat Sheet — Analysis of Experimental Data

> The full pipeline used in the lab: raw data → descriptive stats → outlier exclusion → normality check (histogram + $\chi^2$, NPP) → hypothesis tests (means, variances) → ANOVA → regression → correction of the systematic error. Symbols: $n$ = total data, $q$ = data per group/condition, $k$ = number of groups, $\bar{x}$ = mean, $s$ = sample st.dev., $P$ = confidence level, $\alpha = 1 - P$.

---

## The Pipeline at a Glance

| Step | Question answered | Tool |
| :--- | :--- | :--- |
| 1. Descriptive stats | What does the data look like? | mean, $s$, min/max, median, quartiles, box plot |
| 2. Outlier exclusion | Any measurement accidents? | Chauvenet (or IQR rule) |
| 3. Normality check | Only random effects present? | Histogram + $\chi^2$ test, NPP |
| 4. Hypothesis tests | Which condition/group differs? | z-test on means, $\chi^2$ on variances, t-test |
| 5. ANOVA | Is the factor systematically significant? | $F_{exp} = s_B^2 / s_W^2$ vs Fisher limit |
| 6. Regression | What is the trend (drift)? | Least squares + t-test on parameters + $R^2$ |
| 7. Correction | Remove the systematic effect | Subtract regression trend, re-centre on reference |

---

## 1. Descriptive Statistics & Box Plot

| Quantity | Excel | Notes |
| :--- | :--- | :--- |
| Count, mean, st.dev. | `COUNT`, `AVERAGE`, `STDEV.S` | `STDEV.S` = sample ($n-1$ at denominator) |
| Min, max, median | `MIN`, `MAX`, `MEDIAN` | Box plot whiskers and centre |
| Quartiles | `QUARTILE(data;1)` / `QUARTILE(data;3)` | Box edges; $IQR = Q_3 - Q_1$ |

**First look at the data:** plot in temporal sequence and per condition. Look for drift (monotonic trend), periodic patterns, level jumps between conditions — these are candidate *systematic* factors to verify later.

## 2. Outlier Detection & Exclusion

| Method           | Boundaries                                                               | Character                     |
| :--------------- | :----------------------------------------------------------------------- | :---------------------------- |
| **Chauvenet**    | $x_{lim} =$  `NORM.INV(0.25/n; x̄; s)` and `NORM.INV(1 − 0.25/n; x̄; s)` | Probabilistic, assumes Normal |
| **Classic IQR**  | $[Q_1 - 1.5 \cdot IQR,\; Q_3 + 1.5 \cdot IQR]$                           | Robust, distribution-free     |
| **Modified IQR** | $Q_3 + 1.5 \cdot IQR \cdot \left[1 + 0.1\ln(n/10)\right]$ (sym. below)   | Widens with sample size       |

> [!NOTE] Chauvenet logic
> Conventional probability of finding exactly one accident in the whole experiment $= 50\%$, split between the two tails: each tail gets $\dfrac{0.5}{2n} = \dfrac{0.25}{n}$. Any datum outside the boundaries is a suspect.

**What to do with an outlier** (best → worst): ① repeat the measurement, ② delete the datum, ③ replace with the average (distorts variance — avoid). Never exclude on statistics alone: look for the physical cause. After exclusion, **recompute mean and $s$** and iterate if needed.

## 3. Normality Check A — Histogram + $\chi^2$ Test

### Building the frequency distribution

| Step | Recipe |
| :--- | :--- |
| Examined field | $[\bar{x} - 4s,\; \bar{x} + 4s]$ |
| Number of classes | $n_c \approx \sqrt{n} + 4$ |
| Class width | field / $n_c$ |
| Experimental abs. frequency $f_a$ | `FREQUENCY(data; upper_limits)` |
| Theoretical rel. frequency per class | $F(\text{up}) - F(\text{low})$ = `NORM.DIST(up;x̄;s;1) − NORM.DIST(low;x̄;s;1)` |
| Theoretical abs. frequency $f_t$ | rel. frequency $\times\, n$ |

> [!WARNING] Class width vs resolution (the "WRONG" sheet)
> If the binning rule gives a class width **smaller than the data resolution**, you get unphysical empty classes inside the distribution. Reduce $n_c$ so that width ≥ resolution.

### The test

$$
W = \sum_{j} \frac{(f_{a,j} - f_{t,j})^2}{f_{t,j}} \qquad \nu = n_c - 3
$$

(3 constraints: mean, st.dev., total area = 1.)

**Bilateral** non-rejection interval at confidence $P$: between `CHISQ.INV((1−P)/2; ν)` and `CHISQ.INV(1−(1−P)/2; ν)`. $W$ inside → cannot reject normality. Too high = too different from Normal; too low = suspiciously similar.

> [!TIP] Why a high α (e.g. P = 80%) here?
> Rejecting normality only triggers a simple, routine check of the measurement method — a cheap consequence. So a high $\alpha$ (Type I risk) is acceptable, and it **reduces $\beta$**, the risk of missing real deviations from normality.

## 4. Normality Check B — Normal Probability Plot (NPP)

| Step                            | Formula / Excel                               |
| :------------------------------ | :-------------------------------------------- |
| 1. Sort the data ascending      | rank $i = 1 \dots n$                          |
| 2. Cumulated relative frequency | $F_i = \dfrac{i - 0.5}{n}$                    |
| 3. Standardized quantile        | $z_i =$ `NORM.S.INV(Fᵢ)`                      |
| 4. Theoretical value            | $x_{t,i} = \bar{x} + z_i \, s$                |
| 5. Plot                         | experimental $x_i$ vs $z_i$ (or vs $x_{t,i}$) |

| NPP shape | Meaning | Physical cause |
| :--- | :--- | :--- |
| Straight line | Normal | Only random effects |
| Steeper in the middle (hypernormal) | Tall centre, light tails | Filtering/selection of extreme values |
| Flatter in the middle (hyponormal) | Low centre, heavy tails / bimodal | Discontinuities (2 instruments/operators), drift, wear |

NPP is more sensitive to *shape* distortions than $\chi^2$, but gives no numerical confidence level. Use both.

## 5. Hypothesis Tests on Groups (conditions)

### On the means (z-type test with sample averages)

| Quantity | Formula / Excel |
| :--- | :--- |
| St.dev. of the group average ($q$ data per group) | $s_m = \dfrac{s}{\sqrt{q}}$ |
| Bilateral CI for group means | `NORM.INV((1−P)/2; x̄; sₘ)` … `NORM.INV(1−(1−P)/2; x̄; sₘ)` |
| Decision | Group mean outside CI → systematic effect of that condition |

### On the differences between two group means

$$
s_{\Delta} = s_m \sqrt{2}
$$

CI built around 0 with $s_\Delta$; a difference $\bar{x}_i - \bar{x}_j$ outside → systematic difference between the two conditions. (More sensitive than checking each mean against the global CI.)

### On the variances ($\chi^2$)

Group variance $s_i^2$ compatible with expected $\sigma^2$? With $\nu = q - 1$, the bilateral CI for $s^2$ is

$$
\left[\; \chi^2_{(1-P)/2,\nu} \cdot \frac{\sigma^2}{\nu}\;,\;\; \chi^2_{1-(1-P)/2,\nu} \cdot \frac{\sigma^2}{\nu} \;\right]
$$

Excel: `CHISQ.INV((1−P)/2; ν) * σ²/ν` and `CHISQ.INV(1−(1−P)/2; ν) * σ²/ν`. Group variances outside → dispersion is not homogeneous.

## 6. ANOVA

### Single factor ($k$ groups, $q$ data each)

| Variation cause | Sum of squares | d.o.f. | Variance |
| :--- | :--- | :--- | :--- |
| Examined factor (between) | $SS_B = q \sum_j (\bar{x}_j - \bar{\bar{x}})^2$ | $k - 1$ | $s_B^2 = SS_B/(k-1)$ — in Excel: `VAR.S(group means) * q` |
| Random errors (within) | $SS_W = \sum_j \sum_i (x_{ij} - \bar{x}_j)^2$ | $k(q-1)$ | $s_W^2 = SS_W / [k(q-1)]$ |
| Total | $SS_{TC} = SS_B + SS_W$ | $kq - 1$ | — |

$$
F_{exp} = \frac{s_B^2}{s_W^2} \quad \text{vs} \quad F_{max} = \texttt{F.INV}(P;\, k{-}1;\, k(q{-}1))
$$

$F_{exp} > F_{max}$ → reject $H_0$: the factor **systematically** affects the results.

### Two factors (rows × columns)

$SS_{TC} = SS_{Bc} + SS_{Br} + SS_W$ where $SS_W$ is obtained by difference. Two separate ratios ($s_{Bc}^2/s_W^2$ and $s_{Br}^2/s_W^2$), each against its own Fisher limit.

> [!WARNING] Blind spot
> ANOVA works on discrete groups: a slow continuous drift gets chopped into chunks and may pass unnoticed. Cross-check with the temporal plot and regression.

## 7. Linear Regression (drift identification)

Model (linear in the parameters): $x = c + d\,t$ (I order) or $x = c + d\,t + e\,t^2 + f\,t^3$ (III order), with $t$ = measurement sequence number.

| Step | Excel / Formula |
| :--- | :--- |
| Fit parameters + standard errors | `LINEST(y_range; x_range; 1; 1)` (array formula; row 2 = standard errors $s(a_i)$, also gives $R^2$ and d.o.f.) |
| t-test on each parameter | $t_{exp} = \dfrac{\hat{a}_i - 0}{s(a_i)}$; limits `T.INV((1±P)/2; ν)`; **outside → Significant** |
| Predicted value | $\hat{x}_i = c + d\,t_i \;(+ \dots)$ |
| Residuals | $\epsilon_i = x_i - \hat{x}_i$ |
| Goodness | $R^2 = 1 - \dfrac{\mathbb{V}ar[\epsilon]}{\mathbb{V}ar[x]}$ |

**Residual check:** signs alternating randomly → model adequate; signs grouped → systematic effect remains (raise the order); don't overfit — stop when residuals lose regularity. Residuals can themselves be tested for normality ($\chi^2$ / NPP).

**Choosing the order:** compare I vs III order — keep the higher order only if its extra parameters are statistically *Significant* by the t-test.

## 8. Correction of the Systematic Error

| Step | Formula |
| :--- | :--- |
| Reference value | The general average $\bar{x}$ (used when the drift cause is unknown — no reason to trust initial or final values more) |
| Correction per datum | $\Delta_i = \bar{x} - \hat{x}_i$ (reference minus regression prediction) |
| Corrected value | $x_{corr,i} = x_i + \Delta_i$ |

After correction the trend is removed; corrected data should now pass the normality tests and show no significant factor in ANOVA.

## 10. Typical Conclusions Vocabulary (how to phrase results)

| Situation | Sentence pattern |
| :--- | :--- |
| $W$ inside $\chi^2$ CI | "The test cannot reject the null hypothesis of normality at a confidence level of $P$." |
| Group mean outside CI | "With a risk of error $\alpha$, a systematic difference between condition $i$ and the others is highlighted — investigate condition $i$." |
| $F_{exp} > F_{max}$ | "With a risk of error $\alpha$ there are systematic differences between the conditions." |
| $F_{exp} \le F_{max}$ | "At a confidence level of $P$, systematic differences amongst conditions cannot be highlighted." |
| Choice of high $\alpha$ | "The consequence of a Type I error is only a routine control of the method, so a high $\alpha$ is acceptable and reduces the $\beta$ risk." |
