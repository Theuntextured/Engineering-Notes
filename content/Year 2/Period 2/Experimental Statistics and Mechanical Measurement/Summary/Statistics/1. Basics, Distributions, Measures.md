# Cheat Sheet — Probability & Statistics

> Quick-consult reference for the "Application of Probability and Statistics" exercise set. Symbols: $n$ = sample size, $p$ = probability of "success" (usually *defective*), $q = 1-p$, $\mu$ = mean, $\sigma$ = standard deviation, $s$ = sample standard deviation, $\nu$ = degrees of freedom.

---

## 1. Probability — Core Definitions

| Term | Symbol | Meaning |
| :--- | :--- | :--- |
| Sample space | $S$ | Set of ALL possible outcomes |
| Cardinality | $\#S$ | How many outcomes in $S$ |
| Event | $E \subset S$ | Subset of outcomes we care about |
| Classical probability | $\mathbb{P}[E] = \dfrac{\#E}{\#S}$ | Favourable / possible (all equally likely) |
| Frequentist probability | $\mathbb{P}[E] = \lim\limits_{N\to\infty} \dfrac{n_E}{N}$ | Relative frequency over many trials |

> [!WARNING] Overlapping defects
> If 4 pieces have defect A, 3 have defect B, and 2 have **both**: defective pieces $= 4 + 3 - 2 = 5$, not 7. Always subtract the intersection.

## 2. Probability Rules (the toolbox)

| Rule | Formula | When to use |
| :--- | :--- | :--- |
| Complement | $\mathbb{P}[\bar{E}] = 1 - \mathbb{P}[E]$ | "At least one…" problems: compute "none" and subtract |
| Union, incompatible | $\mathbb{P}(E \cup F) = \mathbb{P}(E) + \mathbb{P}(F)$ | Events cannot happen together |
| Union, compatible | $\mathbb{P}(E \cup F) = \mathbb{P}(E) + \mathbb{P}(F) - \mathbb{P}(EF)$ | Events can overlap (defect A **or** B) |
| Union, 3 events | $\sum \mathbb{P} - \text{(pairs)} + \mathbb{P}(EFG)$ | Inclusion–exclusion |
| Conditional | $\mathbb{P}(E \mid F) = \dfrac{\mathbb{P}(EF)}{\mathbb{P}(F)}$ | "$E$ given that $F$ happened" |
| Product (dependent) | $\mathbb{P}(EF) = \mathbb{P}(F)\,\mathbb{P}(E \mid F)$ | Sequential draws without replacement |
| Product (independent) | $\mathbb{P}(EF) = \mathbb{P}(E)\,\mathbb{P}(F)$ | Independent components/trials |
| Total probability | $\mathbb{P}(A) = \sum_i \mathbb{P}(B_i)\,\mathbb{P}(A \mid B_i)$ | Result from several mutually exclusive causes $B_i$ |
| Bayes | $\mathbb{P}(B_i \mid A) = \dfrac{\mathbb{P}(B_i)\,\mathbb{P}(A \mid B_i)}{\sum_k \mathbb{P}(B_k)\,\mathbb{P}(A \mid B_k)}$ | Reverse: which **cause** given the observed result |

### Combinatorics

| Object | Formula | Order matters? |
| :--- | :--- | :--- |
| Permutations | $\mathcal{P}_n = n!$ | Yes |
| Combinations | $\binom{n}{k} = \dfrac{n!}{k!\,(n-k)!}$ | No |

### Recurring exercise patterns

| Problem | Recipe |
| :--- | :--- |
| Mechanism fails if **any** of its pieces is defective (pieces $A, B, C$ with $P_A, P_B, P_C$) | $\mathbb{P}[\text{fail}] = 1 - (1-P_A)(1-P_B)(1-P_C)$ |
| Same, with $N_A$ pieces of type A, $N_B$ of type B | $\mathbb{P}[\text{fail}] = 1 - (1-P_A)^{N_A}(1-P_B)^{N_B}$ |
| Find max $P_A$ so that $\mathbb{P}[\text{fail}] \le P_1$ | Invert the formula above and solve for $P_A$ |
| Defective part from mixed suppliers (P02) | Total probability: $D = \sum P_i D_i$; then Bayes for "given defective, from B?": $\dfrac{P_B D_B}{D}$ |
| Part defective for A **or** B (or both) | Inclusion–exclusion: $P_A + P_B - P_{AB}$ |
| "If defective, due to both defects?" | Conditional: $\dfrac{P_{AB}}{P_A + P_B - P_{AB}}$ |

## 3. Random Variables & Probability Functions

| Function                                  | Definition                                            | Domain / Output           | Key property                                            |
| :---------------------------------------- | :---------------------------------------------------- | :------------------------ | :------------------------------------------------------ |
| Probability Mass Function (discrete)      | $f_X(x) = \mathbb{P}[X = x_j]$                        | Output $[0,1]$            | $\sum_j f_X(x_j) = 1$                                   |
| Probability Density Function (continuous) | density; $\mathbb{P}[a < X \le b] = \int_a^b f_X\,dx$ | Output $\ge 0$            | Total area $= 1$; single point has $\mathbb{P}=0$       |
| Cumulative Distribution Function (both)   | $F_X(x) = \mathbb{P}[X \le x]$                        | $0 \to 1$, non-decreasing | $f_X = dF_X/dx$; Excel functions with `L=1` return this |

> [!TIP] Everything in exercises is CDFs
> Excel's cumulated option (`TRUE`) gives $\mathbb{P}[X \le x]$. Then:
> $\mathbb{P}[X > x] = 1 - F(x)$  ·  $\mathbb{P}[a < X \le b] = F(b) - F(a)$

## 4. Descriptive Measures

| Measure                  | Formula                                                 | What it tells you                                            |
| :----------------------- | :------------------------------------------------------ | :----------------------------------------------------------- |
| Mean / Expected value    | $\mathbb{E}[X] = \sum x_j f(x_j)$ or $\int x f(x)dx$    | Position (equilibrium point)                                 |
| Variance                 | $\mathbb{V}ar[X] = \mathbb{E}[X^2] - (\mathbb{E}[X])^2$ | Dispersion (squared units)                                   |
| Standard deviation       | $\sigma = \sqrt{\mathbb{V}ar[X]}$                       | Dispersion (same units as $X$)                               |
| Sample variance          | $s^2 = \dfrac{\sum (x_i - \bar{x})^2}{n-1}$             | Estimate of $\sigma^2$ from data                             |
| Coefficient of variation | $CV = \sigma / \mu$                                     | Relative dispersion (unitless)                               |
| Median                   | $F_X = 0.5$                                             | Robust centre (splits probability in half)                   |
| Mode                     | Peak of $f_X$                                           | Most likely value                                            |
| Quantile $x_q$           | Smallest $x$ with $F_X(x) = q$                          | Inverse of the CDF                                           |
| IQR                      | $Q_3 - Q_1$                                             | Robust dispersion                                            |
| Skewness                 | $\mu_3 / \sigma^3$                                      | Asymmetry ($>0$: right tail longer)                          |
| Kurtosis coeff.          | $\mu_4/\sigma^4 - 3$                                    | Tail weight ($>0$ leptokurtic, $0$ normal, $<0$ platykurtic) |

**Handy properties:** $\mathbb{E}[cX] = c\,\mathbb{E}[X]$;  $\mathbb{V}ar[cX] = c^2\,\mathbb{V}ar[X]$;  $\mathbb{E}$ is linear.

## 5. Distributions — Master Table

### Discrete
 
| Distribution         | PMF                                                  | $\mathbb{E}[X]$ | $\mathbb{V}ar[X]$  | Use it when                                                            | Excel                     |
| :------------------- | :--------------------------------------------------- | :-------------- | :----------------- | :--------------------------------------------------------------------- | :------------------------ |
| **Discrete Uniform** | $1/N$                                                | $\frac{N+1}{2}$ | $\frac{N^2-1}{12}$ | $N$ equally likely outcomes                                            | —                         |
| **Bernoulli**        | $p^x q^{1-x}$                                        | $p$             | $pq$               | ONE yes/no trial                                                       | —                         |
| **Binomial**         | $\binom{n}{x} p^x q^{n-x}$                           | $np$            | $npq$              | $n$ independent trials, **with replacement** (or huge batch)           | `BINOM.DIST(k;n;p;L)`     |
| **Hypergeometric**   | $\dfrac{\binom{K}{x}\binom{M-K}{n-x}}{\binom{M}{n}}$ | $n\frac{K}{M}$  | —                  | Sampling **without replacement** from batch of $M$ with $K$ defectives | `HYPGEOM.DIST(k;n;C;M;L)` |
| **Poisson**          | $\dfrac{e^{-\lambda}\lambda^x}{x!}$                  | $\lambda$       | $\lambda$          | Rare events per interval; approximates Binomial                        | `POISSON.DIST(k;λ;L)`     |

### Continuous

| Distribution | Parameters | Use it when | Excel (direct / inverse) |
| :--- | :--- | :--- | :--- |
| **Uniform (rectangular)** | half-width $E$: $\sigma^2 = E^2/3$ | Max error $\pm E$ declared, no other info (Type B) | — |
| **Normal** $N(\mu, \sigma)$ | $\mu$, $\sigma$ | Sums of many random effects; production dimensions | `NORM.DIST(x;m;s;L)` / `NORM.INV(P;m;s)` |
| **Standard Normal** $N(0,1)$ | $z = \dfrac{x - \mu}{\sigma}$ | Normalized comparisons, tables | `NORM.S.DIST(z;L)` / `NORM.S.INV(P)` |
| **Student's t** | $\nu = n - 1$ | Mean CI with **small samples**, $\sigma$ unknown (use $s$) | `T.DIST(t;ν;L)` / `T.INV(P;ν)` |
| **Pearson's $\chi^2$** | $\nu$ | Variance tests, normality ($\chi^2$) test | `CHISQ.DIST(x;ν;L)` / `CHISQ.INV(P;ν)` |
| **Fisher's F** | $\nu_1$ (num.), $\nu_2$ (den.) | Ratio of two variances, ANOVA | `F.DIST(x;m;n;L)` / `F.INV(P;m;n)` |

> [!NOTE]+ Which distribution for batch control?
> - Batch **huge** or "many pieces" → **Binomial** ($p$ stays constant per draw).
> - Batch **small/finite** and no replacement → **Hypergeometric** (exact).
> - $n$ large, $p$ tiny → **Poisson** shortcut.

### Approximation chain

| From → To | Conditions | Substitution |
| :--- | :--- | :--- |
| Hypergeometric → Binomial | $M, K$ large, $n \le M/10$ | $p = K/M$ |
| Binomial → Poisson | $n \ge 100$, $p \le 0.05$ | $\lambda = np$ |
| Binomial → Normal | $np$ and $nq$ large ($\gtrsim 5$) | $\mu = np$, $\sigma = \sqrt{npq}$ |

## 6. Normal Distribution — Working Recipes

| Task | Recipe |
| :--- | :--- |
| $\mathbb{P}[x < a]$ | `NORM.DIST(a; m; s; 1)` — or standardize: $z = \frac{a-\mu}{\sigma}$, then $\Phi(z)$ |
| $\mathbb{P}[x > b]$ | $1 - F(b)$ |
| $\mathbb{P}[a < x < b]$ | $F(b) - F(a)$ |
| Left boundary $x_i$ for lower risk $\alpha_i$ | $x_i =$ `NORM.INV(αᵢ; m; s)` |
| Right boundary $x_s$ for upper risk $\alpha_s$ | $x_s =$ `NORM.INV(1 − αₛ; m; s)` |
| Bilateral CI at confidence $P$ | risk per tail $= \frac{1-P}{2}$; limits `NORM.INV((1−P)/2)` and `NORM.INV((1+P)/2)` |

**Memorize:** $\mu \pm 1\sigma \approx 68.3\%$ · $\mu \pm 2\sigma \approx 95.4\%$ · $\mu \pm 3\sigma \approx 99.7\%$ · $P=95\%$ bilateral → $z = 1.96$.

### Separating two products (S09/S10 type)

Two normal populations $T_1(m_1, s_1)$, $T_2(m_2, s_2)$: find selection limit $L$ with **equal risks** of misclassification. Impose

$$
\mathbb{P}[x_1 > L] = \mathbb{P}[x_2 < L] \quad\Rightarrow\quad \frac{L - m_1}{s_1} = \frac{m_2 - L}{s_2}
$$

(same $\lvert z \rvert$ on both sides; solve for $L$).

## 7. Acceptance Sampling (batch control exercises)

| Plan                                                                           | Risk of accepting a bad batch                                                                                                                                             |
| :----------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Single phase:** test $n$, accept if $\le k$ out of tolerance                 | $\mathbb{P}[\text{accept}] = \sum_{x=0}^{k} \binom{n}{x} p^x q^{n-x} =$ `BINOM.DIST(k;n;p;1)`                                                                             |
| **Exact (finite batch $M$, $K$ defectives):**                                  | `HYPGEOM.DIST` cumulated up to $k$                                                                                                                                        |
| **Two phases:** phase 1 accepts if $\le n_1$, rejects if $> n_2$, else phase 2 | Total probability: $\mathbb{P}[\text{acc}] = \mathbb{P}[\text{acc phase 1}] + \sum_{j} \mathbb{P}[j \text{ defects in ph.1}] \cdot \mathbb{P}[\text{acc in ph.2} \mid j]$ |
| **Find min $n$** for target risk $\alpha$                                      | Increase $n$ until cumulated binomial $\le \alpha$ (trial and error / inverse)                                                                                            |
| **Mixed supplies** ($N_A$ at $D_A$ + $N_B$ at $D_B$)                           | Total defectives $K = N_A D_A + N_B D_B$, population $M = N_A + N_B$ → hypergeometric                                                                                     |

## 8. Inference: Confidence Intervals & Hypothesis Tests

### Confidence intervals

| Estimating | Statistic | Distribution | Interval |
| :--- | :--- | :--- | :--- |
| Mean, $\sigma$ known | $z = \dfrac{\bar{x} - \mu}{\sigma/\sqrt{n}}$ | Normal | $\mu \pm z_{1-\alpha/2}\,\dfrac{\sigma}{\sqrt{n}}$ |
| Mean, $\sigma$ unknown (small $n$) | $t = \dfrac{\bar{x} - \mu}{s/\sqrt{n}}$ | Student, $\nu = n-1$ | $\mu \pm t_{1-\alpha/2,\nu}\,\dfrac{s}{\sqrt{n}}$ |
| Variance | $v = (n-1)\dfrac{s^2}{\sigma^2}$ | $\chi^2$, $\nu = n-1$ | between $\chi^2_{\alpha/2}$ and $\chi^2_{1-\alpha/2}$ |

> [!IMPORTANT] Standard deviation of the mean
> Averages of $q$ values scatter less than single values: $s_m = \dfrac{s}{\sqrt{q}}$. Always use $s_m$, not $s$, when testing a **sample mean**.

### Hypothesis test — 4 steps

1. **State $H_0$** (always: "no difference, variation is only random").
2. **Choose the distribution** (Normal/z, Student/t, $\chi^2$, F).
3. **Set the risk** $\alpha$ → confidence $P = 1 - \alpha$ (bilateral: $\alpha/2$ per tail).
4. **Compute limits of non-rejection zone**; if the experimental statistic falls **outside** → reject $H_0$ (systematic effect exists).

### Errors of first and second kind

| | Reality: $H_0$ true | Reality: $H_0$ false |
| :--- | :--- | :--- |
| **Test rejects** | Type I error — risk $\alpha$ (false alarm) | Correct ✓ |
| **Test accepts** | Correct ✓ | Type II error — risk $\beta$ (missed change) |

**$\beta$ risk recipe (S08 type):** build the CI $[L, U]$ from the *original* process at confidence $P$; then $\beta = \mathbb{P}[L \le x \le U]$ computed with the **new** distribution $(m_1, s_1)$: $\beta = F_1(U) - F_1(L)$.

### Which test for which question?

| Question | Test | Statistic |
| :--- | :--- | :--- |
| Does this sample mean belong to the known population? | z-test | $z = \dfrac{\bar{x} - \mu}{s/\sqrt{q}}$ |
| Are two sample means compatible? (small samples) | t-test | CIs per sample with Student t; no overlap → systematic difference |
| Is this sample variance compatible with $\sigma^2$? | $\chi^2$-test | $v = (q-1)\dfrac{s^2}{\sigma^2}$ |
| Are two variances equal? / Does a factor matter? | F-test / ANOVA | $F_{exp} = s_B^2 / s_W^2$ vs Fisher limit |
| Is the data Normal? | $\chi^2$ normality test | $W = \sum \dfrac{(f_a - f_t)^2}{f_t}$, $\nu = \text{classes} - 3$ |

## 9. Excel Statistical Functions — Quick Reference

| Function | Inputs | Returns |
| :--- | :--- | :--- |
| `BINOM.DIST(k;n;p;L)` | successes $k$, trials $n$, prob $p$ | $L{=}0$: $\mathbb{P}[X{=}k]$ · $L{=}1$: $\mathbb{P}[X{\le}k]$ |
| `HYPGEOM.DIST(k;n;C;M;L)` | $k$ in sample, sample $n$, $C$ defectives in pop., pop. $M$ | same as above (no inverse exists) |
| `POISSON.DIST(k;λ;L)` | $k$, mean rate $\lambda$ | same as above |
| `NORM.DIST(x;m;s;L)` | value, mean, st.dev. | $L{=}0$: PDF · $L{=}1$: CDF |
| `NORM.INV(P;m;s)` | cumulated probability | the $x$ such that $F(x) = P$ |
| `NORM.S.DIST(z;L)` / `NORM.S.INV(P)` | standardized $z$ | standard normal CDF / inverse |
| `T.DIST(t;ν;L)` / `T.INV(P;ν)` | $t$, dof $\nu$ | Student CDF / inverse |
| `CHISQ.DIST(x;ν;L)` / `CHISQ.INV(P;ν)` | $x$, dof $\nu$ | Pearson CDF / inverse |
| `F.DIST(x;m;n;L)` / `F.INV(P;m;n)` | $x$, num. dof $m$, den. dof $n$ | Fisher CDF / inverse |

> [!TIP] The `L` flag
> `L = 0` (FALSE) → point/density value. `L = 1` (TRUE) → **cumulated** probability $\mathbb{P}[X \le x]$ — this is what you want 95% of the time.

## 10. Decision Flowchart — "Which tool do I need?"

| The exercise says… | Reach for… |
| :--- | :--- |
| "Probability of picking a defective piece from a batch" | Classical: $\#E / \#S$ (mind overlapping defects!) |
| "Mechanism fails if any component is defective" | Complement of product: $1 - \prod (1-P_i)^{N_i}$ |
| "Given it's defective, which supplier?" | Bayes |
| "Any of several defect types present" | Inclusion–exclusion (union) |
| "Extract $n$ pieces, accept if $\le k$ defective" | Cumulated Binomial (or Hypergeometric if batch is small/finite) |
| "Two control phases" | Total probability over phase-1 outcomes |
| "Compare exact vs approximate" | Hypergeometric vs Binomial, or Binomial vs Poisson |
| "Probability that $x$ is below / above / between" | Normal CDF (direct function) |
| "Find the boundary for a given risk $\alpha$" | Normal inverse function |
| "Separate two products with equal risk" | Equal-$z$ condition: $\frac{L-m_1}{s_1} = \frac{m_2-L}{s_2}$ |
| "Did the modification/repair change the process?" | Bilateral hypothesis test on the mean ($s_m = s/\sqrt{n}$) |
| "Risk of not detecting the change" | $\beta$ (second kind): new distribution evaluated over old CI |
| "Maximum error $\pm E$, no distribution given" | Uniform distribution: $\sigma^2 = E^2/3$ |
