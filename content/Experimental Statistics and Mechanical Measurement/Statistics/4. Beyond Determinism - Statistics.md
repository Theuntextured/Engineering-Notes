## Core Concepts
* **Random Phenomenon:** Physical event with a non-deterministic, a priori unknown outcome.
* **Random Experiment:** Experiment that yields different outcomes even if repeated exactly the same way.
* **Statistics:** The science of data; methods of collecting, analysing, and reporting data to make decisions.

## Random Variables (R.V.)
* Associates an event in the sample space $S$ to a real number on the $\mathbb{R}$ axis.

| Type | Codomain (Image) | Example |
| :--- | :--- | :--- |
| **Discrete** | Isolated points | Dice roll, number of defective parts. |
| **Continuous** | Intervals | Height, temperature, part dimensions. |

## Probability Functions
> [!NOTE] PMF vs. PDF
> Discrete variables use a Probability Mass Function (PMF), while continuous variables use a Probability Density Function (PDF).

### 1. Discrete: Probability Mass Function (PMF)
* $f_X(x) = \mathbb{P}[X = x_j]$ for mass points $x_j$, else $0$.
* Properties: Output is $[0,1]$, always $\ge 0$, and the sum across all mass points equals $1$.

### 2. Continuous: Probability Density Function (PDF)
* Represents probability density over an interval; exact points have infinitesimal probability.
* Properties: Output is $\mathbb{R}^+$, always $\ge 0$, and the total area under the curve (integral over $\mathbb{R}$) equals $1$.
* Probability over an interval $[a, b]$ is the integral of the PDF:

$$
\mathbb{P}[a < X \le b] = \int_{a}^{b} f_X(x)dx
$$

### 3. Cumulative Distribution Function (CDF)
* $F_X(x) = \mathbb{P}[X \le x]$.
* Properties: Output is $[0,1]$, limits are $0$ (at $-\infty$) and $1$ (at $+\infty$), monotonous non-decreasing, right-continuous.
* Relationship to PDF:

$$
F_X(x) = \int_{-\infty}^{x} f_X(u)du
$$

$$
f_X(x) = \frac{dF_X(x)}{dx}
$$

## Distribution Parameters

### Position Indexes
* **Expected Value / Mean ($\mathbb{E}[X]$):** Central equilibrium point (only true centre if symmetric).
  * Discrete: 

$$
\mathbb{E}[X] = \sum_{x_j} x_j f_X(x_j)
$$

  * Continuous: 

$$
\mathbb{E}[X] = \int_{-\infty}^{+\infty} x f_X(x)dx
$$

* **Quantiles ($x_q$):** Smallest $x_q$ where $F_X(x_q) = q$.
* **Quartiles:** $Q_1$, $Q_2$ (Median), $Q_3$.
* **Median ($med(X)$):** Splits probability exactly in half ($\mathbb{P}[X \le med] \ge 0.5$).
* **Mode:** The peak (most frequent value) of the distribution.

### Dispersion Indexes
* **Variance ($\mathbb{V}ar[X]$):** Measures how far elements are from the mean.
* **Standard Deviation ($\sigma$):** $\sqrt{\mathbb{V}ar[X]}$.
* **Shortcut Variance Formula**:

$$
\mathbb{V}ar[X] = \mathbb{E}[X^2] - (\mathbb{E}[X])^2
$$

* **Coefficient of Variation (CV):** Standard Deviation / Average.
* **Interquartile Range (IQR):** $Q_3 - Q_1$.

### Shape Indexes (Moments)
* **$n$-th order central moment:** $\mu_n = \mathbb{E}[(X - \mathbb{E}[X])^n]$.
* **Skewness (Asymmetry):** $\mu_3 / \sigma^3$. 
  * Alternative: $(\text{mean} - \text{mode}) / \text{standard deviation}$.
* **Kurtosis:** Indicates tail weight/peakedness.
  * Kurtosis Coefficient = $(\mu_4 / \sigma^4) - 3$.
  * $\mu_4 / \sigma^4 > 3 \rightarrow$ Leptokurtic.
  * $\mu_4 / \sigma^4 = 3 \rightarrow$ Normal.
  * $\mu_4 / \sigma^4 < 3 \rightarrow$ Platykurtic.

> [!INFO] Properties of Expected Value & Variance
> $\mathbb{E}[c \cdot g(X)] = c \cdot \mathbb{E}[g(X)]$
> $\mathbb{E}[c_1 \cdot g_1(X) + c_2 \cdot g_2(X)] = c_1 \cdot \mathbb{E}[g_1(X)] + c_2 \cdot \mathbb{E}[g_2(X)]$
> $\mathbb{V}ar[c \cdot X] = c^2 \cdot \mathbb{V}ar[X]$

## Main Discrete Distributions

### 1. Discrete Uniform
* **Use:** All $N$ outcomes equally likely.
* $f_X(x) = 1/N$.
* $\mathbb{E}[X] = (N+1)/2$.
* $\mathbb{V}ar[X] = (N^2-1)/12$.

### 2. Bernoulli
* **Use:** Single binary trial (Success = $p$, Failure = $1-p = q$).
* $\mathbb{E}[X] = p$.
* $\mathbb{V}ar[X] = pq$.

### 3. Binomial
* **Use:** $n$ independent Bernoulli trials (sampling *with replacement*).

$$
f_X(x) = \binom{n}{x} p^x (1-p)^{n-x}
$$

* $\mathbb{E}[X] = np$.
* $\mathbb{V}ar[X] = npq$.

### 4. Hypergeometric
* **Use:** Sampling *without replacement* (probabilities change per draw). Used in industrial batch testing.
* $M$ = total batch, $K$ = total defectives, $n$ = sample size.

$$
f_X(x) = \frac{\binom{K}{x} \binom{M-K}{n-x}}{\binom{M}{n}}
$$

* $\mathbb{E}[X] = n(K/M)$.
* **Approximation:** If $M, K$ are large and $n \le M/10$, you can approximate using Binomial where $p = K/M$.

### 5. Poisson
* **Use:** Events occurring in a fixed interval; models rare events.

$$
f_X(x) = \frac{\exp(-\lambda)\lambda^x}{x!}
$$

* $\mathbb{E}[X] = \lambda$.
* $\mathbb{V}ar[X] = \lambda$.
* **Approximation:** Can approximate a Binomial distribution when $n \to \infty$ ($n \ge 100$) and $p \to 0$ ($p \le 0.05$) by setting $\lambda = np$.
