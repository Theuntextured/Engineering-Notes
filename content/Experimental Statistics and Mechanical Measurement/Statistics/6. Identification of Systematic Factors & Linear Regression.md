## Searching for Systematic Factors
* Normality tests ($\chi^2$ and NPP) indicate the *presence* of systematic factors, but they do not *identify* them.
* To identify them, you must examine the global trend of the data, such as plotting data in temporal sequence to spot a drift (monotonic trend over time).

## The Linear Regression Procedure
Regression identifies the functional relationship between independent variables ($X$) and the dependent variable ($Y$).

### Step 1: Assume a Mathematical Model
* Select a curve (e.g., straight line, parabola, exponential) based on visual data trends and physical laws.

### Step 2: Calculate Parameters (Least Squares Method)
* Used to find the coefficients ($a_i$) of the chosen model.
* **Crucial condition:** The model must be linear *with respect to its parameters*. 
    * *Valid (Linear):* $Y = a_0 + a_1 X + a_2 X^2$
    * *Valid (Linear):* $Y = a_0 + a_1 e^X$
    * *Invalid (Non-Linear):* $Y = a_0 + e^{a_1 X}$ (Requires complex non-linear regression).
* Minimizes the sum of the squares of the deviations (residuals, $\epsilon_i$) between experimental values and the regression curve.
* Matrix formulation of the system:

$$
\{y\} = [1, x]\{a\} + \{\epsilon\}
$$

* The parameters vector $\{a\}$ is solved analytically as:

$$
\{a\} = [[1, x]^T [1, x]]^{-1} [1, x]^T \{y\}
$$

### Step 3: Evaluate Residuals
* **Residuals** ($\epsilon$) are the differences between experimental values and calculated model values.
* If the model successfully corrects the systematic factors, the residuals will only contain random effects.
* **Sign Grouping:** 
    * Random pattern (frequent alternation of + and - signs) $\rightarrow$ Model is adequate.
    * Signs group together $\rightarrow$ Systematic factor remains; model is inadequate (e.g., using a 1st-order line when a 2nd-order curve is needed).
* **Danger of Overfitting:** Do not endlessly increase the polynomial order. It will artificially track random factors. Stop increasing the order once the residuals lack "regularity".
* Residuals can be formally tested for normality using $\chi^2$ or NPP to rigorously evaluate goodness of fit.

## Calibration vs. Use Equations
* **Equation of Calibration:** Uses the variable with the lowest uncertainty (e.g., the reference standard) as the independent variable.
* **Equation of Use:** Uses the instrument's output as the independent variable to calculate the unknown measurand.
* For instruments with regular metrological characteristics, both equations yield compatible results, allowing you to rely on the more comfortable Equation of Use.

## A Posteriori Evaluation Metrics
Besides evaluating residuals, you must verify the model's overall statistical goodness:

### 1. Hypothesis Test of Parameters (t-test)
* Tests if a parameter $a_i$ is statistically significant.
* Null Hypothesis $H_0: a_i = 0$.
* Reject $H_0$ (meaning the parameter is significant) if the experimental value $t_{exp}$ falls outside the Confidence Interval (CI):

$$
t_{exp} = \frac{\hat{a_i} - 0}{s(a_i)}
$$

### 2. Coefficient of Determination ($R^2$)
* Describes the percentage of variability explained by the model.
* Ranges from $0 \le R^2 \le 1$ (closer to 1 is better).

$$
R^2 = 1 - \frac{\mathbb{V}ar[\epsilon]}{\mathbb{V}ar[y]}
$$
